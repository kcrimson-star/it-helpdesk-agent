    NovaDesk REST API Specification

    Integrate ticketing, AI triage, and conversational troubleshooting directly into external systems

    Interactive OpenAPI Swagger
    POST /api/triage/classify
    Classify & Diagnose with AI

    Submits raw issue text to the LangChain Groq model and returns category, ITIL priority, solutions, and KB matches.

    curl -X POST "http://localhost:8000/api/triage/classify" \
  -H "Content-Type: application/json" \
  -d '{
    "issue_description": "GlobalProtect VPN timeout error 502 while connecting",
    "requester_name": "Sarah Connor",
    "system_info": "macOS Sonoma 14.5"
  }'
    POST /api/tickets
    Create Support Ticket

    Creates a new ticket. Automatically triggers AI classification and solution attachment if auto_diagnose is true.

    curl -X POST "http://localhost:8000/api/tickets" \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Lenovo laptop blue screens with BitLocker prompt after BIOS update",
    "requester_name": "Marcus Vance",
    "requester_email": "m.vance@company.corp",
    "department": "Finance",
    "auto_diagnose": true
  }'
    GET /api/tickets
    Query Tickets

    List tickets with status, priority, category, search filters and pagination.

    curl -X GET "http://localhost:8000/api/tickets?status=Open&priority=Critical"
    POST /api/agent/chat
    Conversational Troubleshooting

    Interactive multi-turn conversation with the IT Helpdesk agent with automatic structured diagnosis extraction.

    curl -X POST "http://localhost:8000/api/agent/chat" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "My Outlook calendar is refusing to sync new invites",
    "history": []
  }'
